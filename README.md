# Paulo Kushino

**Backend Developer** com foco em **Java/Spring** e **QA Automation**, também construindo interfaces com **Angular** e **Next.js**.

Gosto de entregar sistemas confiáveis: API bem modelada, testes automatizados, migrations versionadas e CI/CD desde o primeiro commit.

## 👋 Sobre

- Desenvolvimento backend com Java 21 + Spring Boot, APIs REST, JPA/Hibernate e PostgreSQL/MySQL.
- Testes em camadas: unitários (JUnit + Mockito), integração (Testcontainers), contrato (REST Assured) e E2E (Playwright/Cypress).
- Frontend quando necessário: Angular, Next.js, TypeScript e Tailwind CSS.
- **Aberto a oportunidades em backend (Java/Spring) e QA Automation.**
